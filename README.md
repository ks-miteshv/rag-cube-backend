# RAG Cube Backend

A backend application for RAG (Retrieval-Augmented Generation) using Cube.js for analytics.

## Setup Instructions

### Prerequisites

- Docker and Docker Compose
- PostgreSQL database

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd rag-cube-backend

2. Configure environment variables:

    ```bash
    cp .env.example .env
    ```

3. Start the services

    ```bash
    docker compose up
    ```
